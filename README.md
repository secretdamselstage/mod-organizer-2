# Mod Organizer 2

### Advanced mod manager for Bethesda and other games

Mod Organizer 2 is the most powerful mod manager for Bethesda games and beyond. Its virtual file system means mods never touch your base game files, enabling safe installation, easy removal, and perfect conflict resolution.

<br>

---

## Features

| | |
|:---|:---|
| **Virtual File System** | Mods overlay the game directory without modifying original files |
| **Conflict Visualization** | See exactly which mod wins each file conflict with a detailed view |
| **Profile System** | Multiple separate mod profiles — switch between setups instantly |
| **Plugin Support** | Extensible with community plugins for additional games and features |
